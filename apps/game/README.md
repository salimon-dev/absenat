# Absenat

A tile-based exploration game built with Phaser 4 and React 19.

## 🚀 Getting Started

### 📦 Installation
```bash
npm install
```

### 🛠 Development
To start the development server:
```bash
npm run dev
```

### 🏗 Build
To build the project for production:
```bash
npm run build
```

### 🎨 Asset Generation
To regenerate the world tilemap:
```bash
npm run generate-tiles
```
